# VerveMind AI - Portfolio

A collection of AI automation and DevOps case studies by Sameed (Sammy) Uddin.

This repository serves as the source of truth for my professional portfolio. Each folder within `/case-studies/` contains a detailed write-up of a project, outlining the problem, the solution, and the results.

## Case Studies

1.  **[Drift-Focus: A Fully Automated Generative AI YouTube Channel](./case-studies/01-drift-focus/README.md)**
    *   An n8n pipeline that orchestrates AI models (Google Veo 3, external audio) to autonomously generate, produce, and publish unique video content.

2.  **[VerveMind Ops Kit: A Real-Time Project Command Center](./case-studies/02-vervemind-ops-kit/README.md)**
    *   A lightweight, self-hosted Kanban/Dashboard system built with Node.js and Server-Sent Events (SSE) for instantaneous, organization-wide updates.

3.  **[Mission Control 2.0: Internal Command Center](./case-studies/03-mission-control-2-0/README.md)**
    *   A unified operations dashboard with n8n-backed APIs for Gmail captures and Notion tasks.
